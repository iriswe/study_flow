## 一、产品定位

### 1.1 产品名称

**StudyFlow**（暂定）

### 1.2 一句话定义

> 面向长期学习者的桌面学习管理系统，帮助用户形成"目标 → 任务 → 学习 → 记录 → 复习 → 强化"的完整学习闭环。

### 1.3 核心价值

区别于普通 Todo 应用，本产品重点解决：
- 学了什么（学习记录）
- 学会了多少（掌握程度）
- 哪些容易遗忘（FSRS 复习算法）
- 什么时候该复习（间隔提醒）
- 什么时候该复习（间隔提醒）
- 长期学习是否持续（数据统计）

### 1.4 目标用户

| 用户群体 | 特点 | 核心需求 |
|----------|------|----------|
| **程序员** | 长期自学、内容复杂、需持续复习 | 学习路线管理、技术知识复习、进度追踪 |
| **考证用户** | 备考周期长、高频复习需求 | 长期计划、高频复习、进度控制 |
| **长期自学者** | 易半途而废、缺乏反馈 | 学习闭环、正反馈、数据可视化 |

### 3.4 Study Log（学习记录）

**定位：** 记录每次学习的时长、笔记和理解程度。

#### 3.4.1 学习记录列表

- 按日期分组展示
- 显示：任务名、学习时长、理解程度、学习时间
- 支持搜索和日期筛选

#### 3.4.2 创建学习记录

| 字段 | 类型 | 说明 |
|------|------|------|
| 关联任务 | 下拉，必填 | 本次学习的任务 |
| 学习时长 | 数字（分钟），必填 | 可手动输入或来自 Focus Mode |
| 笔记内容 | Markdown 文本，可选 | 笔记内容，图片以 `![](url)` 引用 |
| 理解程度 | 枚举 | 不理解 / 模糊 / 理解 / 精通 |
| 遇到的问题 | 多行文本，可选 | 记录难点 |
| 附件 | 图片 URL 数组，可选 | 上传图片存 OSS，独立存储方便列表展示 |

#### 3.4.3 笔记编辑器

- 基础富文本功能：加粗、斜体、标题、列表、代码块
- 支持图片粘贴上传至 OSS
- 自动保存草稿

#### 3.4.4 富文本图片处理流程

```
用户粘贴图片 → 前端预览(base64) → 上传 OSS → 获取 URL → 写入 Markdown → 提交保存
```

**存储策略：**
- `note` 字段：存 Markdown 纯文本，图片以 `![](https://oss.xxx.com/img.png)` 引用
- `image_urls` 字段：单独存图片 URL 数组（JSON），方便列表页展示缩略图

**优势：**
- 数据库字段小（只存 URL，不存 base64）
- 图片 CDN 分发，OSS 成本低
- 导出 Markdown 无损兼容

### 3.5 Review（复习系统）

**定位：** 基于 FSRS 算法的间隔复习系统。

#### 3.5.1 复习原理（FSRS 算法）

FSRS（Free Spaced Repetition Scheduler）是新一代间隔重复算法，相比 SM-2 具有更高的记忆效率。

**核心参数：**

| 参数 | 说明 |
|------|------|
| stability | 记忆稳定度（天），初始值由算法根据首次反馈确定 |
| difficulty | 难度系数（0-10），初始 5.0 |
| reponse | 用户反馈：-3忘记/-2模糊/0好/3简单 |

**间隔计算逻辑：**
- 首次学习：生成初始稳定度，根据反馈调整
- 复习阶段：根据上次间隔 × 上次表现计算下次间隔
- 间隔上限：默认 365 天

**默认复习节奏（参考）：**
| 反馈 | 间隔 |
|------|------|
| 忘记（-3） | 1 分钟 → 10 分钟 |
| 模糊（-2） | 维持原间隔 × 0.5 |
| 良好（0） | 原间隔 × 1.5 |
| 简单（3） | 原间隔 × 2.5 |

**相比 SM-2 优势：**
- 自动适应个人记忆曲线
- 支持不稳定记忆检测
- 复习效率提升约 30%

#### 3.5.2 复习队列页

- 卡片展示待复习项目
- 正面：问题 / 任务名
- 反面：揭示答案 / 笔记摘要
- 操作：忘记 / 模糊 / 记住 / 跳过 / 延后

#### 3.5.3 复习通知

- 本地通知：复习提醒（可配置时间）
- 客户端启动时检查并提醒

### 3.6 Focus Mode（专注模式）

**定位：** 番茄工作法 + 全屏专注。

#### 3.6.1 番茄钟

#### 3.6.2 专注界面

- **普通专注：** 侧边栏显示计时器，背景可继续操作

- **计时控制：** 开始 / 暂停 / 跳过 / 结束

#### 3.6.3 数据同步

- 专注完成后自动创建对应任务的学习记录
- 时长自动填入 Study Log

## 十一、竞品分析

### 11.1 竞品痛点对比

| 痛点 | 印象笔记 | 飞书/Notion | Obsidian |
|------|----------|-------------|----------|
| 同步慢/失败 | 高频 | 中 | 高（第三方） |
| 离线体验差 | 低 | 高 | 低（本地） |
| 编辑卡顿 | 中 | 低 | 低 |
| 学习成本高 | 低 | 高（数据库） | 中（插件） |
| 移动端体验 | 中 | 中 | 差 |
| 数据可控性 | 低 | 中 | 高（本地） |

### 11.2 竞品用户认可的功能

| 功能 | 来源 | 借鉴价值 |
|------|------|----------|
| 双向链接 | 印象笔记/Notion/Obsidian | 任务之间可建立关联关系 |
| 模板功能 | Notion | 学习记录可预设模板 |
| OCR 扫描 | 印象笔记 | v2 可考虑（PDF解析） |
| 进度可视化 | 各产品仪表盘 | Dashboard 核心价值 |
| 本地存储 | Obsidian | 离线优先架构基础 |

### 11.3 StudyFlow 设计决策

基于竞品分析，MVP 重点解决：

| 设计决策 | 落地方式 |
|----------|----------|
| **同步可靠性** | 本地 SQLite 为核心 + 云端同步，设计重试机制和冲突处理 |
| **离线优先** | 核心功能离线可用，网络恢复后自动同步 |
| **快速记录** | Ctrl+N 快速创建，Space 快速完成，降低操作成本 |
| **学习效果可视化** | 复习后立即显示间隔变化，让用户感知进步 |
| **进度醒目** | Dashboard 首屏展示连续天数、完成率等核心指标 |
| **信息密度高但不杂乱** | 参考 Obsidian 风格，颜色区分优先级，布局紧凑 |

### 11.4 避免的竞品问题

| 避免项 | 原因 |
|--------|------|
| 编辑器卡顿 | 笔记内容多了之后如果卡顿，用户会直接放弃 |
| 同步丢失数据 | 一旦出现数据丢失，信任感难以挽回 |
| 功能过于复杂 | 学习成本高会让用户流失 |
| 移动端体验差 | 桌面端优先，但移动端也要基本可用 |
